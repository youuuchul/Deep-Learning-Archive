# 모델 양자화 (Quantization)

## 개요

모델 양자화란 신경망의 가중치/활성값을 부동소수점(FP32)에서 저비트 정수(INT8 등)로 변환해 모델 크기를 줄이고 추론 속도를 높이는 기법.

## 핵심 트레이드오프

| 항목 | FP32 | INT8 (양자화 후) |
|------|------|-----------------|
| 정밀도 | 높음 | 약간 저하 (보통 1% 이내) |
| 모델 크기 | 기준 | ~25% (이론상 4배 압축) |
| 추론 속도 | 기준 | CPU에서 2~4배 빠름 |
| 메모리 | 기준 | 줄어듦 |

## 양자화 종류

### 1. 동적 양자화 (Dynamic Quantization)
- **시점**: 추론 시 실시간으로 활성값 양자화
- **대상**: FC 레이어, LSTM (가중치는 INT8, 활성값은 런타임에 계산)
- **장점**: 별도 캘리브레이션 데이터 불필요, 구현 단순
- **단점**: Conv 레이어 미지원, 속도 이득 제한적

```python
quantized_model = torch.quantization.quantize_dynamic(
    model,
    {nn.Linear},     # 대상 레이어 타입
    dtype=torch.qint8
)
```

### 2. 정적 양자화 (Static/Post-Training Quantization, PTQ)
- **시점**: 학습 후, 캘리브레이션 데이터로 스케일 사전 계산
- **대상**: Conv 포함 전체 레이어
- **장점**: 동적 양자화보다 빠름, Conv 지원
- **단점**: 캘리브레이션 데이터 필요, 준비 과정 복잡

### 3. 양자화 인식 학습 (Quantization-Aware Training, QAT)
- **시점**: 학습 중에 양자화 효과 시뮬레이션
- **대상**: 전체 레이어
- **장점**: 가장 정확도 손실 적음
- **단점**: 재학습 필요, 시간 비용

## MNIST 실험 결과 (이 미션)

- 동적 양자화 적용 (FC 레이어만)
- 이론: 4배 압축 → 실제: FC 비중이 작은 CNN은 효과 제한적
- Conv 레이어 가중치는 FP32 유지

## 실무 선택 가이드

```
배포 환경에 캘리브레이션 데이터 있음?
  Yes → PTQ (정적 양자화) 우선
  No  → 동적 양자화 (텍스트 모델/LSTM에 효과적)

정확도 손실 0.1% 이하 요구?
  Yes → QAT (재학습 필요)
  No  → PTQ로 충분
```
