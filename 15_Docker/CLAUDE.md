# 기본 가이드 러프
- Mission_Guide.md 에 적은 시나리오 기반 준수
- Plan.md 수정/검토 하면서 맞게 진행 -> 진행전 확인
- 환경 설정 uv 활용
- 노트북 및 코드 logger 활용
- 데이터는 해석 가능하도록, 노트북 출력물 검증하면서 확인이 필요할경우 나한테 결과물을 보여주며 물어볼 것
- 차트 시각화는 plotly 라이브러리 활용
- 노트북에서 작업하는 것들 폴더구조 레포에 맞게 출력물 불규칙적으로 쌓이지 않게 정돈하면서
- 마지막 결과 보고서 html 기반 및 pdf 출력 고려
- src, notebook 기능이나 폴더별로 readme 간략하게라도 작성해서 검토 가능하도록 할 것


# 에이전트 관련 준수사항
- ai_history에 중요 프로세스별로 .md 파일 정리 잘하기
- 프롬프트, 사용 모델, 툴(클로드,안티그래비티,코덱스 등) 과정과 결과 작성하여 추후 검토하도록
- 진행 후 관련 작업물 명시
- 관련 스터디/학습 필요할 것 제안도 남기기
- .claude에 skills, rules 작성 정리 필요시 제안 후 작성 : 추후 다른 프로젝트에서 검토하여 일관성 있게 확장할 수 있도록
