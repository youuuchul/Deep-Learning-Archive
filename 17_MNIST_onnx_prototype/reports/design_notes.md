# 설계 결정 메모 — 보고서 작성용

## 미션 가이드 대비 변경 사항

### 원본 가이드 스펙
> 이미지 저장소: 사용자가 그린 이미지를 저장하고, 각 이미지와 함께 예측된 레이블 및 확률을 표시

### 실제 구현 방향 및 이유

**변경 1: 예측 버튼 제거 → 실시간 자동 예측**
- 가이드에는 별도 예측 버튼을 가정
- 실제 구현: 캔버스에 획이 그려지는 즉시 (`json_data.objects` 감지) 자동 추론
- 이유: UX 개선 — 버튼 클릭 없이 즉각적인 피드백 제공, 숫자 인식 앱의 본질에 더 적합

**변경 2: 세션 기반 이미지 저장소 → PNG 다운로드**
- 가이드: session_state에 이미지 목록 누적 표시
- 실제 구현: 예측 결과(레이블, 확률, 전처리 이미지)를 합성한 PNG를 직접 다운로드
- 이유: 브라우저 새로고침 시 세션 초기화로 저장 데이터 소실 → 파일 다운로드가 더 실용적

**변경 3: 저장 이미지 합성 (추가 구현)**
- 단순 28×28 grayscale PNG 저장 → 예측 레이블 + 신뢰도 + 확률 바 포함 합성 이미지로 개선
- 저장 파일에서 어떤 숫자를 그렸고 모델이 어떻게 판단했는지 한눈에 확인 가능

## 보고서에 남길 내용 (초안)

### 구현 특이사항 섹션
```
본 구현은 미션 가이드의 기본 스펙을 충족하면서, UX 관점에서 두 가지를 개선했습니다.

첫째, 별도 예측 버튼 대신 실시간 자동 추론을 적용했습니다.
streamlit-drawable-canvas의 json_data.objects를 활용해
실제 획이 존재할 때만 모델을 호출하도록 구현했으며,
빈 캔버스 입력 시 모든 클래스 확률이 0으로 표시됩니다.

둘째, 세션 기반 이미지 저장소 대신 PNG 다운로드 방식을 채택했습니다.
저장 파일에는 전처리된 28×28 이미지와 함께 예측 레이블,
신뢰도, 전체 클래스 확률 바를 합성하여 결과를 직관적으로 확인할 수 있습니다.
```
